# Акции и скидки

Секция подключена после избранных товаров. Референс содержания — https://www.pechnik.su/, блок `#stockList`. Остальные секции сохранены.

## Файлы

Созданы: `src/components/home/promotions/PromotionsShowcase.astro`, `PromotionCard.astro`, `images.ts` в том же каталоге; `src/data/promotions.ts`, `src/types/promotion.ts`, `src/styles/components/_promotions-showcase.scss`; `scripts/test-promotions-static.mjs`, `scripts/test-promotions-browser.mjs`, `scripts/fixtures/promotions.astro.txt`; этот документ.

Изменены: `src/pages/index.astro`, `src/styles/main.scss`, `src/scripts/main.ts`, `README.md`. Четыре изображения в `assets/images/stocks/` уже присутствовали в рабочем дереве; файлы и пользовательские изменения `assets/tabsData.json` не изменялись.

## API и данные

`PromotionsShowcase`: `items: readonly PromotionItem[]` — обязательный массив; `title` по умолчанию «Акции и скидки»; `allPromotionsUrl` по умолчанию `#`; `maxItems` по умолчанию 4. Лимит округляется вниз и ограничивается диапазоном 0–4; нечисловые/бесконечные значения заменяются на 4. Используется `slice`, исходный массив не меняется. При пустом результате секция отсутствует. Несколько экземпляров получают уникальные идентификаторы заголовков.

`PromotionCard` принимает `item: PromotionItem`. Модель: `{ name: string; img: string; url?: string }`. Демонстрационный массив импортирует только страница; названия, пути и порядок сохранены.

## Внешний вид и доступность

Вертикальная карточка: одинаковая область 16:9 сверху, полное название снизу. Одна ссылка охватывает оба элемента; вложенных ссылок нет. Высота естественная, карточки одного ряда выравнивает Grid. Manrope, цвета, отступы, радиусы, тень и длительности берутся из существующих токенов. Есть hover, active, focus-visible и reduced motion.

До 576px — 1 колонка, от 576px — 2, от 992px — 4; стандартный Bootstrap `.container` и существующие breakpoint mixins.

Все исходные JPG имеют размер 550×309; обычный `img` использует `object-fit: contain`, центрирование, intrinsic width/height, lazy loading и async decoding. Область резервируется через aspect-ratio. Изображения импортируются существующим подходом `import.meta.glob` и получают production URL Astro без изменения исходных файлов. Для отсутствующего локального изображения выводятся предупреждение сборки и текст «Изображение недоступно». Публичные/HTTP(S) пути также поддерживаются. У текущих изображений нет дополнительного рекламного текста, поэтому `alt=""` исключает повтор названия. Если будущий баннер содержит дополнительные условия, при интеграции необходимо предоставить их текстовый эквивалент.

## Ссылки и JS

Отсутствующий, пустой или отклонённый существующим `safeUrl` URL заменяется на `#`. Демонстрационные ссылки явно отмечаются `data-demo-link`. Единственный делегированный обработчик в `main.ts` предотвращает действие только отмеченных ссылок с точным `href="#"`. Настоящие URL и якоря сохраняют нативный переход даже при оставшемся data-атрибуте. Секция и изображения рендерятся без JS; предотвращение прокрутки демонстрационного `#` требует общего JS. Без JS действует обычное поведение якоря браузера.
