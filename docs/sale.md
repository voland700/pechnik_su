# Страница акций

/sale/ использует CatalogLayout с меню showcaseData, как на странице каталога. Sidebar виден от 768 px, на мобильных скрыт общими стилями. H1, Breadcrumbs, Header и Footer остаются общими.

Данные: src/data/sale.json, четыре предложения в исходном порядке. SaleItem принимает item (title, date, text, img) и необязательный eager. Изображения подключаются через существующий promotionImage и выпускаются в dist/assets. Первое eager, остальные lazy; размеры из метаданных.

До 992 px изображение на всю ширину, текст ниже. От 992 px — Grid с изображением 280 px слева. Общие токены, focus-visible и shine; SCSS в main.scss. Клиентского JS нет.

Для Битрикс сохранить article, классы и три независимые ссылки; заменить # на URL акции. HTML описания перед set:html должен быть доверенным или очищенным. Даты преобразуются в ISO при сборке; отображаемые строки сохранены.
