# Детальная страница контактов

Маршрут: `/about/contacts/pechnoy-tsentr-yasenevo-tsentralniy-sklad/`.
Используется CatalogLayout с `showSidebar={false}`, общие Header, Footer, main и Breadcrumbs.

`src/data/contact-detail.ts` содержит контактные данные, ссылки карт, исходные изображения Astro с размерами и массив 12 пар `img` / `preview` с описаниями. `ContactDetail.astro` формирует основной контент, `ContactGallery.astro` — галерею. При переносе в Битрикс заменить данные, сохранив структуру HTML и data-атрибуты.

SCSS подключён через общий main.scss, использует токены и стандартные breakpoint mixins. Галерея: 2 колонки до 768 px, 3 от 768 px, 4 от 1200 px. Телефоны: 2 колонки от 768 px. Карточки карт вертикальные до 768 px, затем 3 в ряд. QR отображается целиком без эффектов. Две `.contact-map__placeholder` имеют высоту 256 / 352 px; их содержимое заменяется картами при интеграции с CMS. API и iframe не подключаются.

Глобальный Fancybox автоматически обслуживает отдельные группы `yasenevo-scheme` и `yasenevo-gallery`. Ссылки галереи используют существующий `.shine`, миниатюры загружаются лениво, href ведёт на оригинал. Дополнительного JS и зависимостей нет.

Проверки: `npm run check`, `npm run build` (включая verify-dist). Браузерный smoke-тест production-сборки: запустить `npm run preview -- --host 127.0.0.1`, затем `node reference/test-contact-detail.mjs`. Нужен установленный Chrome; путь можно задать через CHROME_PATH. Проверяются ширины 375/576/768/992/1200/1440, отсутствие переполнения, изображения, сетка, ссылки, focus, заглушки, открытие Fancybox, переключение и закрытие. Отчёт и скриншоты сохраняются в reference/.

Существующая ссылка «О печном центре» ведёт на `/about/`, как и на странице списка; сам раздел пока не реализован. Существующие предупреждения сборки относятся к устаревшему Sass @import Bootstrap и отсутствующему демонстрационному изображению ProductCard на главной.
