# ProductCard

Демонстрация: `/products-demo/`, ссылка есть в UI Kit. 12 синтетических состояний и изменяемый по ширине контейнер. Цены не являются предложением магазина.

## Файлы и API

- `src/components/catalog/ProductCard.astro` — самостоятельная карточка, ` <ProductCard product={item} />`. Родитель задаёт сетку.
- `src/components/catalog/images.ts` — разрешение существующих изображений из `assets/images/products`, public и HTTP(S). Отсутствующий локальный ресурс вызывает предупреждение и текст «Изображение недоступно». Для внешних изображений доступность проверяет поставщик данных.
- `src/types/product.ts` — согласованный интерфейс `ProductItem`, строгие флаги и предел количества.
- `src/data/products-demo.ts`, `src/pages/products-demo.astro` — данные и демонстрация.
- `src/styles/components/_product-card.scss`, `src/styles/pages/_products-demo.scss` — БЭМ, общий CSS через `main.scss`.
- `src/scripts/modules/product-card.ts` — условный импорт через `main.ts`.
- `scripts/test-product-card-browser.mjs` — Chrome CDP smoke test без новых зависимостей; `SHOWCASE_BASE_URL` задаёт адрес preview.

```ts
export interface ProductItem {
  id: number | string;
  name: string;
  img: string;
  url?: string;
  price: string;
  old_price: string;
  new: boolean | 0 | 1;
  hit: boolean | 0 | 1;
  sale: boolean | 0 | 1;
  inStock: boolean | 0 | 1;
  discount: string;
  canBuy: boolean | 0 | 1;
}
```

## Поведение

Только `true` и `1` включают флаг. Строковые флаги отвергаются; CMS-адаптер обязан явно преобразовать их. Цена — непустая строка после trim; runtime null и другие типы трактуются как отсутствие. Строковые цены выводятся без арифметики, валюта добавляется шаблоном. При отсутствии цены старая цена скрыта, покупка и количество нативно отключены. `purchaseEnabled = normalizeFlag(canBuy) && hasPrice`. `inStock` отвечает только за подпись.

Все активные лейблы находятся сверху изображения; наличие снизу слева, скидка снизу справа. Название сохранено целиком и визуально ограничено двумя строками. Ссылки принимают относительные и HTTP(S) адреса через существующий `safeUrl`. Отсутствующий/опасный URL и `#` дают семантическую отключённую ссылку без перехода и без попадания в Tab-порядок.

Количество независимо для каждой формы: целое 1–999. Пустое, отрицательное, дробное, экспоненциальное и некорректное значение сбрасывается к 1 при change/blur/submit; превышение ограничивается 999. Нормализация выполняется до события, в том числе при Enter. `noValidate` включается только после установки JS-обработчика.

Количество и кнопка компактные, высотой 2.25rem и всегда расположены в одном ряду без переноса. Container query от 19rem меняет только отступы тела карточки. Отступы изображения уменьшены до 1.5rem / .25rem / 2rem, размер лейблов — .8rem. Общая высота не фиксирована; flex выравнивает нижнюю часть в строке родительской сетки. Используются Manrope, общие токены, нативный disabled и общий focus/reduced-motion.

`initProductCards(root = document)` можно вызывать повторно после AJAX-вставки; WeakSet исключает повторные обработчики. Например: `const { initProductCards } = await import('./modules/product-card'); initProductCards(insertedContainer);`. Автоматический MutationObserver не используется. Формы `method="dialog"` исключают HTTP-отправку даже без JS (карточка предназначена для обычного контейнера, вне dialog). Обработчик предотвращает submit и выдаёт всплывающее `product-card:demo-submit` с `{ productId: string, quantity: number }`. Событие означает только проверку входных данных, а не добавление в корзину.

## Передача в Битрикс

| Frontend | Источник CMS / ответственность адаптера |
| --- | --- |
| id | ID элемента или покупаемого торгового предложения |
| name | NAME |
| img | URL DETAIL_PICTURE/PREVIEW_PICTURE |
| url | DETAIL_PAGE_URL |
| price | Форматированная доступная пользователю цена без валюты |
| old_price | Форматированная базовая цена без валюты либо пустая строка |
| new, hit, sale | Согласованные свойства инфоблока → boolean/0/1 |
| inStock | Согласованный признак наличия, независимо от CAN_BUY |
| discount | Готовый текст скидки либо пустая строка |
| canBuy | CAN_BUY предложения с учётом прав и правил CMS → boolean/0/1 |

Имена свойств инфоблока согласовываются при интеграции. Сохранить классы, доступные имена и data-атрибуты, подключить общий CSS и main.js с чанками. Заменить демонстрационный обработчик и method формы реальной интеграцией CMS; на сервере повторно проверить ID, количество, права, актуальную цену, доступность и CSRF. Реальные адреса товаров подставить вместо заглушек.

Корзины, HTTP API, хранения покупок и Bitrix API здесь нет. Ограничение 999 относится к интерфейсу и не является складским остатком. Кратность, SKU и валюты вне текущего контракта.

## Проверки реализации

`npm run check`: 0 ошибок, предупреждений и подсказок. `npm run build` и `npm run verify:dist` успешны: 2 страницы, единые CSS-варианты, JS-чанки и 85 локальных ссылок. Сохраняются существующие Sass deprecation warnings от Bootstrap.

Отдельно проверены строгая нормализация boolean/0/1 с отклонением строк, runtime null цены, границы и некорректные значения количества, наличие 13 карточек и безопасного method в собранном HTML.

Браузерный сценарий подготовлен, но запуск в текущей среде дважды остановился по тайм-ауту Chrome CDP на Runtime.enable. Визуальная проверка, реальный ввод/клавиатура, ширины viewport и контейнера, динамическая вставка, отсутствие ошибок консоли требуют повторного запуска в доступном браузере. Это не считается пройденной browser-проверкой.

Референс https://teplo-marine.ru/catalog/category/pechi-dlja-bani просмотрен через веб-инструмент; он показывает названия, цены и элементы покупки. Исходный DOM `div.list_inner` недоступен через текстовое представление, прямой HTTP-запрос из рабочей среды не прошёл. Точное визуальное соответствие референсу не проверено.
