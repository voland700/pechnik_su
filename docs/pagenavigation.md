# Pagenavigation

Общий компонент `src/components/common/Pagenavigation.astro` размещён рядом с Breadcrumbs, не зависит от каталога. На `/category/` подключён после `.catalog-products` внутри контента CatalogLayout. Структура — nav с доступным названием, ul/li, ссылки и неинтерактивные span. Стрелки используют существующий Icon/arrow; SVG декоративны и скрыты от скринридера.

```astro
---
import Pagenavigation from '../components/common/Pagenavigation.astro';
---
<Pagenavigation />
<!-- Проверить другие состояния без создания страниц: currentPage={3} или {5}. -->
<Pagenavigation currentPage={3} totalPages={5}
  links={{ 1: '/news/', 2: '/news/page/2/', 4: '/news/page/4/', 5: '/news/page/5/' }} />
```

Примеры независимы. Props:

- `currentPage`: текущий номер, по умолчанию 1.
- `totalPages`: готовое положительное целое количество страниц, по умолчанию 5. Компонент не вычисляет его из числа товаров или других данных.
- `links`: карта номер → URL. Ссылки стрелок берутся из соседних номеров, даже если они не входят в видимый набор. Используется существующий safeUrl.
- `pages`: необязательный готовый набор номеров; `null` обозначает многоточие. Без него выводится простой ряд от 1 до totalPages. Например, для длинного списка: `currentPage={3} totalPages={12} pages={[1, 2, 3, null, 12]}`. CMS отвечает за корректность набора: номера уникальны и находятся в диапазоне, текущая страница включена.

По умолчанию доступные ссылки имеют `href=""`: нативно открывают текущий документ, не переключают набор товаров. Это может перезагрузить документ; реальных страниц 2–5 пока нет. Скриптов, обработчиков, URL-генератора, вычисления общего числа страниц и загрузки данных нет. При интеграции CMS подставляет текущий номер, количество страниц, видимые номера и реальные URL; самостоятельные ссылки работают нативно.

Текущая страница — span с aria-current="page", приглушённым фоном и полужирным текстом. На первой странице предыдущая стрелка, на последней следующая стрелка — span с aria-disabled="true", без href/tabindex. Остальные элементы — a с hover/focus-visible. Доступные названия стрелок: «Предыдущая страница» и «Следующая страница». Многоточие — неинтерактивный span, скрытый от скринридера.

Стили `_pagenavigation.scss` подключены в `main.scss`. Используются существующие токены. Пагинация центрируется относительно родителя, имеет верхний отступ space-6. Высота элементов — 44 px; до sm ширина от 36 px с интервалом 4 px, выше — от 44 px с интервалом 8 px. Все семь элементов демо помещаются в одну строку на 320 px. Для более длинного переданного списка есть flex-wrap; для компактной одной строки CMS должна передавать сокращённый набор через pages. Глобальный reduced motion подавляет переходы. Новых breakpoints, библиотек, шрифтов и цветов нет.

Проверки: `npm run check`, `npm run build`, `scripts/test-pagenavigation-browser.mjs` и регрессия `scripts/test-catalog-section-browser.mjs`. Браузерные тесты запускаются на preview через SHOWCASE_BASE_URL, при необходимости CHROME_PATH. Тест пагинации рендерит реальные компоненты через Astro Container и проверяет состояния 1/3/5, ссылки CMS, многоточие, декоративные SVG, отсутствие скриптов/обработчиков, фокус и reduced motion. Все три состояния проверены на 1440/1024/768/390/320 px: одна строка, центрирование, высота элементов и отсутствие переполнения. JS страницы отключён. Артефакты — `artifacts/pagenavigation/`.

Сборка: 5 страниц, два CSS, 277 ссылок на ресурсы. Сохранились предупреждения Bootstrap Sass, отсутствующее изображение на главной `assets/images/main_XEWTaZkyPl.jpg` и прежняя подсказка о неиспользуемом параметре теста featured products. Отдельных команд lint/typecheck нет; Astro и TypeScript проверяет check. Firefox/Safari и ручной скринридер не проверялись.
