# Hero Slider

Главная подключает `<HeroSlider slides={sliderData} autoplay />` перед сохранённым UI Kit. Другие разделы магазина не добавлены. Композиция опирается на `assets/slide_exempl.jpg`; существующий сайт https://www.pechnik.su/ изучен как дополнительный источник. API сверено с https://swiperjs.com/swiper-api и установленным Swiper 14.3.0.

## Файлы и интерфейс

- `src/components/home/hero-slider/HeroSlider.astro` — оболочка, props, независимые элементы управления.
- `HeroSlide.astro` — слои и условные ссылки одного слайда.
- `content.ts` — разрешённые URL, локальные ресурсы через Vite, ограничение HTML и overlay.
- `src/types/hero-slider.ts` — `HeroSlideData`.
- `src/data/hero-slider.ts` — четыре исходных предложения без изменения коммерческих условий.
- `src/scripts/modules/hero-slider.ts` — отдельная инициализация `[data-hero-slider]`, WeakMap против повторного запуска.
- `src/styles/components/_hero-slider.scss` — изолированный БЭМ-блок в общей CSS-сборке.
- Изменены `src/pages/index.astro`, `src/scripts/main.ts`, `src/styles/main.scss`; конфигурация Astro и зависимости для слайдера не менялись.
- `scripts/test-hero-browser.mjs`, `scripts/fixtures/hero-check.astro.txt` — воспроизводимые проверки Chrome; `artifacts/hero/` — скриншоты и результаты.

Props: `slides` (массив, пустой ничего не выводит), `autoplay=false`, `delay=6000` (минимум 6000 мс), `loop=true`, `showNavigation=true`, `showPagination=true`, `defaultOverlay` (тёмный сине-зелёный градиент). Один слайд не зацикливается, не запускает autoplay и не выводит управление.

Входные поля `name`, `text`, `link`, `backgraund`, `img` сохранены, включая исходную опечатку. Необязательны все поля кроме `name`; расширения: `imageWidth`, `imageHeight`, `overlay`, `backgroundPosition`. В демонстрационных данных записаны реальные размеры PNG: 435×400, 430×400, 400×417, 435×400. При неизвестных размерах CSS резервирует область с aspect-ratio. Фоны 1280×500, 42–79 КБ; PNG 33–81 КБ. Vite выпускает локальные файлы с хешами, повторное копирование изображений в public не требуется.

## Композиция и поведение

Переключение Hero использует модуль EffectFade: `effect: 'fade'`, `fadeEffect: { crossFade: true }`. CSS эффекта включён в общую сборку. Parallax слоёв сохранён; reduced motion по-прежнему обнуляет длительность переключения. Демонстрационный Swiper не изменён.

Актуальные размеры после уточнений: боковые отступы 20 px на Mobile, 32 px на Tablet (от 768 px), `clamp(3rem, 5vw, 5rem)` — 48–80 px на Desktop (от 992 px). Описание на всех ширинах имеет `font-size: 1.1rem` (17.6 px при корневом 16 px). У кнопки «Подробнее» шрифт .95rem и внутренние отступы уменьшены на 5%; минимальная область нажатия 44 px по высоте сохранена. Эти значения заменяют размеры из предыдущих итераций ниже.

Весь слайдер ограничен стандартным Bootstrap `.container` и центрирован: фон и overlay также находятся в его границах. Внешний контейнер без padding, внутренний сохраняет отступы сетки. Затемнение правой точки градиента усилено с .3 до .6 (на 30 процентных пунктов).

Уточнение Desktop-композиции: от 992 px контент и управление имеют одинаковые боковые отступы `clamp(2rem, 4vw, 4rem)` (32–64 px). Вложенные Bootstrap container удалены; внутренние области занимают доступную ширину с собственными отступами. Заголовок уменьшен с 40 до 30 px, описание с 20 до 15 px (−25%). Мобильная типографика сохранена. Эти значения заменяют первоначальные Desktop-размеры ниже.

Отдельный абсолютный фон с `object-fit: cover` (эквивалент background-size: cover) имеет запас 2% для Parallax. Это настоящий img: первый фон eager/high, остальные lazy. Первая товарная иллюстрация eager, остальные lazy; все используют contain. Затемнение лежит между фоном и контентом; inline background позволяет менять overlay по слайдам. Blur не используется.

Контент ограничен Bootstrap container. На ширинах от 768 px две колонки, минимальная высота 424 px, от 992 px — 448 px. Изображение ограничено 352 px по высоте, заголовок 40 px. Высота текста не фиксируется: при большом содержимом слайдер естественно растёт. Все слайды растянуты до высоты самого высокого, скачков autoHeight нет. Жёсткий max-height сознательно не применяется к контейнеру с произвольным CMS-текстом, чтобы не обрезать условия акций.

На мобильном текст сверху, товар снизу, минимальная высота 608 px; нижняя зона зарезервирована под управление. Используются Manrope 400/600/700, существующие токены, золотой акцент `brand-gold` для читаемости на тёмном фоне. Списки без маркеров, как в референсе. Стили описания ограничены `.hero-slider__description`.

Swiper: модули Navigation, Pagination, A11y, Parallax, Autoplay; speed 700 мс, loop по props при нескольких слайдах, watchOverflow. Стрелки используют существующий Icon. Клавиши ←/→ обрабатываются только внутри hero, чтобы не управлять другими каруселями. Неактивные слайды inert. A11y-сообщения переведены на русский.

Parallax: фон −1% / 1000 мс; заголовок −40 px / 700 мс; описание −60 px / 850 мс; кнопка −80 px / 950 мс; товар +50 px / 800 мс и scale .95. Текстовые слои и товар изменяют opacity от 0. Длительности намеренно короче исходных трёх секунд для чтения без ожидания.

Autoplay на главной включён, интервал 6 секунд. Hover временно приостанавливает; focus внутри, скрытая вкладка также приостанавливают. Свайп, навигация и клик по ссылке останавливают до явного возобновления. Кнопка «Пауза» / «Продолжить» доступна с клавиатуры. Возобновлённый autoplay ждёт выхода фокуса из карусели. Reduced motion отключает autoplay и Parallax, обнуляет переходы и скрывает кнопку автоуправления; изменения системной настройки применяются без перезагрузки. Без JS все слайды доступны последовательно, управление скрыто.

Ссылка выводится только при непустом безопасном URL. Заголовок и «Подробнее» используют один href; `#` сохраняет видимость демонстрационного состояния, но JS отменяет прокрутку. При пустом URL нет ни ссылки заголовка, ни кнопки. Клик по всей площади не реализован.

## HTML, overlay и Битрикс

HTML-описание выводит только p, ul, li, br, span, strong, em без атрибутов. Исторические обёртки div и классы исходного массива удаляются при рендеринге; сами данные сохранены. Inline-обработчики и style не переносятся. Это дополнительное ограничение контролируемых исходников, а не замена полноценного серверного санитайзера.

Backend обязан очистить HTML полноценным sanitizer по указанному allowlist без атрибутов; экранировать `name` и значения атрибутов шаблона; проверять URL (относительные либо HTTP/HTTPS, без javascript/data/protocol-relative/control characters); разрешать доверенные хосты изображений согласно политике магазина. Публичные CMS URL должны быть доступны браузеру. Для локального развёртывания под префиксом проверить BASE_URL и пути CMS отдельно.

Overlay допускает HEX 3/4/6/8 символов или ограниченные linear/radial-gradient с числовыми rgb/rgba/hsl/hsla/HEX цветами. URL, var(), произвольные декларации не поддерживаются; неизвестное значение заменяется defaultOverlay. Именованные цвета в градиентах не входят в текущий контракт. Backend должен валидировать грамматику и контрастность; frontend не гарантирует контрастность произвольного выбранного администратором цвета.

При переносе в Битрикс сохранить HTML-слои, классы, data-атрибуты, локальный контекст controls и модульный entry point; скопировать dist/assets, dist/css, dist/js. Подключить один style.min.css. PHP/Bitrix API не используются. Менять данные можно независимо от хранения в CMS. Реальные ссылки и коммерческие условия согласуются владельцем сайта.

## Проверки и ограничения

`npm run check`: 0 errors / warnings / hints. Production build и verify:dist проходят; sandbox препятствовал разрешению внутренних модулей Astro, вне sandbox сборка успешна. Сохранились существующие Sass warnings Bootstrap 5.2.

Chrome smoke: 390, 576, 768, 1024, 1440, 1920 px; все четыре слайда, загрузка фоновых и товарных img, отсутствие пересечений текста/товара и горизонтального overflow, наличие CTA только на первых двух слайдах, активный текст видим, overlay, стрелки, пагинация, клавиши, # без прокрутки, реальное автопереключение после ожидания, reduced motion во время работы, наличие Parallax-transform, независимый DemoSlider, отсутствие browser errors. Скриншоты — artifacts/hero.

Для edge fixtures временно скопировать scripts/fixtures/hero-check.astro.txt в src/pages/hero-check.astro, собрать и запустить preview; установить HERO_TEST_FIXTURES=1 и выполнить `node scripts/test-hero-browser.mjs`. После проверки удалить временную страницу и пересобрать production. Chrome запускается headless, путь переопределяется CHROME_PATH.

Edge fixtures также прошли в Chrome: пустой массив, один слайд без controls/loop/autoplay, отсутствие необязательных изображений, отклонение javascript-ссылки, удаление обработчиков и style из HTML, HEX-overlay. Временная страница удалена, финальная production-сборка и повторный Chrome smoke успешны.

Не выполнены сертификация Safari/Firefox, проверка на физическом touch-устройстве, ручная проверка экранным диктором и измерения Lighthouse/LCP/CLS. Touch обеспечивает штатный Swiper; отдельный жест не проверен. Нет необоснованного preload: первый фон приоритетен через img без дублирования запроса. WebP/AVIF и responsive srcset — возможная следующая оптимизация после измерений. Рекламные # необходимо заменить реальными URL перед публикацией магазина.
