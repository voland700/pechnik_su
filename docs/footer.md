# Footer

`src/components/layout/Footer.astro` выводится по умолчанию в footer-слоте `BaseLayout` на всех трёх страницах. Статический HTML не требует JavaScript. Header не изменён.

`src/data/footer.ts` содержит три меню (24 временных ссылки), социальные ссылки, контакты и координаты платёжных логотипов. При переносе в Битрикс замените массивы данными меню и настроек сайта. Содержимое `.site-footer__vk-widget` заменяется компонентом сообщества; сейчас используется исходный `assets/vk.jpg` с заданными размерами для резервирования места. Реального виджета и подписной формы нет.

SCSS подключён через `main.scss`. Используются Manrope, существующие secondary/text/muted/action/border/surface цвета и spacing-токены. Стандартный Bootstrap container: до 1320 px. До md (768 px) блоки вертикальные, меню центрированы; от md — три колонки; от xl (1200 px) — пять колонок, нижняя строка горизонтальная. Контакты всегда выровнены влево внутри группы. Высота определяется содержимым.

Предоставленные социальные и контактные SVG вставляются inline на этапе сборки. У социальных файлов отсутствует xmlns, поэтому inline-вставка также обеспечивает корректность отображения. Логотипы сохраняют свои цвета; контактные контуры используют currentColor. Декоративные SVG скрыты от скринридеров.

`pay_icons.svg` — полоса 547 × 22 без symbol. Исходная графика вставляется один раз в SVG defs/g, идентификаторы масок, фильтров и градиентов получают префикс footer-pay-. Двенадцать SVG с индивидуальными viewBox ссылаются на эту группу через use. Исходные пропорции сохранены, Flexbox допускает перенос. Каждый логотип имеет доступное название и не является ссылкой.

Проверки: `npm run check`, `npm run build`, `node scripts/test-footer-browser.mjs`. Последняя команда использует установленный Chrome через CDP, без зависимостей; путь можно задать через CHROME_PATH. Проверяются 375/768/1024/1440 px, число колонок, отсутствие переполнения, 24 ссылки, безопасность пяти внешних ссылок, четыре контакта, 12 SVG, загрузка VK, копирайт, клавиатурный фокус и все три страницы без JS. Скриншоты и результаты сохраняются в `artifacts/footer/`.
