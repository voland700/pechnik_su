# Страница раздела каталога

Маршрут: `/category/`, исходник — `src/pages/category/index.astro`. После `npm run build` создаётся отдельный готовый HTML-файл `dist/category/index.html` для переноса в CMS. Страница полностью генерируется при сборке (`output: 'static'`), серверный рендеринг не используется. При переносе вместе с HTML нужны общие ресурсы `dist/assets/`, `dist/css/` и `dist/js/` с сохранением путей.

Используется существующий `CatalogLayout` без изменений: он выводит единственный H1, Breadcrumbs, sidebar и основной slot. Навигация создаётся из `showcaseData` точно так же, как на `/catalog/`. Для промежуточного раздела «Чугунное и печное литьё» маршрут пока не существует, поэтому Breadcrumbs выводит текст без выдуманной ссылки.

## Компоненты и данные

- `CatalogNotices.astro`: необязательный `items: CatalogNotice[]`. Сообщение — строка либо массив `{ text: string, strong?: boolean }`. Astro экранирует текст; произвольный HTML не поддерживается. Отсутствующие, пустые и состоящие из пробелов сообщения не создают контейнеров.
- `CatalogSubcategories.astro`: необязательный `items: CatalogSubcategory[]` с полями `name`, `img`, `url`. Один элемент списка содержит одну ссылку на всю карточку. Пустой массив или отсутствие prop не создаёт разметки.
- `src/data/rubtsovsk-casting.ts`: 12 категорий в исходном порядке с исходными путями и `url: '#'`; единственное релевантное уведомление о стоимости и наличии.
- `src/types/catalog-section.ts`: типы данных для замены источника на CMS.
- `_catalog-section.scss`: изолированные БЭМ-классы через общий `main.scss`, существующие токены и breakpoint mixins. Глобальные правила и существующие компоненты не меняются.

Дальнейшие товары или другое содержимое добавляются в default slot страницы после компонентов, независимо от наличия уведомлений и вложенных категорий.

## Изображения и доступность

Все 12 файлов найдены в корневом `assets/images/categories/`, не в `public`. `import.meta.glob` получает ImageMetadata и Vite выпускает браузерные URL `/assets/...` без копирования исходников. У изображений реальные width/height, lazy loading, async decoding и object-fit contain. Пустой alt исключает повтор названия той же ссылки скринридером. При неизвестном пути отображается текст «Изображение недоступно» вместо сломанного img.

Список семантический, названия переносятся; hover и focus подчёркивают название. Используется существующий focus-visible с отступом внутрь карточки и глобальное правило reduced motion. Клиентский JS не добавлен.

## Адаптивность

- До 768 px: компактные горизонтальные строки с областью изображения 48 × 48 px; sidebar скрывается существующим layout.
- 768–991 px: две колонки с изображениями сверху, sidebar 224 px.
- 992–1199 px: три колонки.
- От 1200 px: четыре колонки, sidebar 240 px.

Desktop-область изображения ограничена 128 × 128 px; высота строки определяется содержимым, ссылки занимают всю карточку.

- `npm run check`: 0 ошибок, 0 предупреждений; существующая подсказка о неиспользуемом параметре в тесте featured products.
- `npm run build`: пять страниц, два CSS, проверены 244 ссылки на ресурсы. Из-за ограничения песочницы на разрешение `astro/entrypoints/prerender` сборка выполнена вне песочницы.
- `node scripts/test-catalog-section-browser.mjs`: headless Chrome, JS страницы отключён; 1440/1024/768/390/320 px, число колонок, геометрия, отсутствие переполнения, порядок 12 категорий, изображения, ссылки, H1, Breadcrumbs, неизменность sidebar, клавиатурный focus-visible, reduced motion, отсутствие ошибок браузера.
- Тот же тест через Astro Container проверяет отсутствие props и пустые массивы обоих компонентов, два уведомления (включая пример об отгрузке кирпича), strong, экранирование HTML и отсутствующее изображение. Для изолированного рендера списка тест подставляет пустую карту изображений; реальные ресурсы проверяются отдельно в браузере.
- `node scripts/test-catalog-browser.mjs`: существующий корневой каталог прошёл регрессионную проверку на 375/768/1024/1440 px.
- Скриншоты 1440 и 320 px просмотрены. Снимки пяти ширин и JSON-отчёт: `artifacts/catalog-section/`.

Существующие предупреждения сборки: Sass deprecated imports Bootstrap и два отсутствующих изображения ProductCard на главной. К новой странице они не относятся. Отдельной команды lint нет. Firefox/Safari и ручная проверка скринридером не выполнялись. Из внешних референсов pechi-tula.ru вернул 403; использованы предоставленные локальные изображения референсов. Публикация и CMS-интеграция не входят в этот этап.
