# Breadcrumbs

`src/components/common/Breadcrumbs.astro` формирует статический `nav > ol > li` без JavaScript. Подключайте один раз непосредственно после H1 каждой внутренней страницы. На главной не подключайте. В текущем этапе компонент добавлен только на `/ui-kit/`.

```astro
---
import Breadcrumbs from '../components/common/Breadcrumbs.astro';
import type { BreadcrumbItem } from '../types/breadcrumbs';
const heading = 'WIKING';
const breadcrumbs: BreadcrumbItem[] = [
  { label: 'Каталог', href: '/catalog/' },
  { label: 'Печи-камины', href: '/catalog/pechi-kaminy/' },
  { label: heading },
];
---
<h1>{heading}</h1>
<Breadcrumbs items={breadcrumbs} />
```

Пути в примере иллюстрируют API; соответствующие страницы не создаются. `BaseLayout` отвечает за HTML-оболочку, header/main/footer, но не H1, поэтому не расширен. Если появится общий блок заголовка внутренних страниц, вызов компонента можно перенести туда.

## Контракт

- `items: BreadcrumbItem[]`, тип экспортируется из `src/types/breadcrumbs.ts`.
- «Главная» автоматически ведёт строго на `/`; её не нужно передавать.
- Последний элемент — текст с `aria-current="page"`, его `href` игнорируется.
- Промежуточные элементы используют переданные URL. Отсутствующий, пустой или равный `#` адрес даёт текст. Корректные и безопасные URL — ответственность источника данных/CMS.
- Пустой массив не выводит навигацию. Написание названий сохраняется, HTML в названиях экранирует Astro.
- Нет разбора URL, генерации slug или JSON-LD. Данные можно позднее использовать для структурированных данных.

## Оформление

SCSS подключён в общий `main.scss`, БЭМ-классы `breadcrumbs__*`. Наследуется Manrope, используются `--text-sm`, `--color-action`, `--color-text`, `--color-muted`, `--space-1/2/5` и глобальный `:focus-visible`. Подчёркивание ссылок сохраняет глобальные правила; при hover меняется цвет.

Список использует flex-wrap; каждый пункт удерживает рядом свой CSS-разделитель. Пустой псевдоэлемент с наклонённой линией визуально изображает `/`, не добавляя озвучиваемого текста. `min-width: 0` и `overflow-wrap: anywhere` позволяют переносить даже длинные названия без пробелов. Нет усечения или прокрутки.

На UI Kit сохранён H1 «Основа для тёплых решений.». H1 и Breadcrumbs вынесены из `.kit-intro` в `.page-heading` — первый блок main сразу после Header. Блок занимает 100% ширины, внутренний `.container` сохраняет общие боковые поля сайта. Ограничение `.kit-intro` в 48rem к заголовку и крошкам больше не применяется.

## Проверки

`npm run check`, `npm run build` (включает проверку ресурсов dist).

`node scripts/test-breadcrumbs.mjs` — установленный Chrome, preview на `http://127.0.0.1:4321` (можно задать `SHOWCASE_BASE_URL` и `CHROME_PATH`). Использует существующие транзитивные инструменты Astro, без новых зависимостей и тестовых маршрутов. Компонент компилируется и рендерится с шестью цепочками и пустым массивом; HTML вставляется в страницу UI Kit для проверки геометрии. Отдельно проверяется исходная production-разметка UI Kit и главной. Отчёт: `artifacts/breadcrumbs/results.json`.

Проверено в headless Chrome с отключённым JS страницы: 375/768/1024/1440 px, глубина до 13 элементов, длинные строки с пробелами и без, отсутствующие URL, ошибочный href текущей страницы, экранирование, последовательность и ссылки, CSS-разделители, отсутствие переполнения, focus-visible. Это не ручной аудит скринридером и не полная кроссбраузерная проверка.
