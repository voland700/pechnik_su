# Монтаж

Маршрут `/installation/` сохранён из `src/data/navigation.ts`. Страница использует `CatalogLayout` с `showSidebar={false}`: общий Header, Footer, единственный main, H1 и Breadcrumbs.

Восемь независимых компонентов находятся в `src/components/montage/`, данные — в `src/data/montage.ts`. Изображения импортируются как Astro ImageMetadata из `assets/images/montage/`, имеют исходные размеры. Оригиналы не изменяются. Все шесть отзывов выводятся полностью на этапе сборки.

SCSS `src/styles/pages/_montage.scss` подключён через `main.scss`. Используются общие токены и Bootstrap breakpoints. Услуги: 1/2/3 колонки; категории: 1/2/4; преимущества: 2/3; опыт: 2/3/6; галерея: 2/4; отзывы: 1/2. Проблемы и решения хранятся и выводятся парами, с 768 px занимают две равные колонки. Схема ограничена исходной шириной и масштабируется целиком.

Fancybox обслуживается существующей глобальной делегированной инициализацией. Группы `montage-gallery` (4 фото) и `montage-plan` (схема) независимы. Дополнительных библиотек, инициализаций и гидратации нет.

Четыре ссылки категорий ведут на заданные будущие CMS-маршруты; соответствующих локальных страниц пока нет. Их точные адреса внесены в существующий plannedRoutes в `scripts/verify-dist.mjs`, реализованный `/installation/` удалён из исключений.

Проверки: `npm run check`, `npm run build` (включает проверку ресурсов). Для браузерного smoke-теста запустить preview, затем `node reference/test-montage.mjs`. При другом порте задать `SHOWCASE_BASE_URL`. Нужен установленный Chrome; путь настраивается через `CHROME_PATH`. Тест проверяет 320/375/390/576/768/992/1200/1440/1920 px, отсутствие переполнения, число секций и карточек, сетки, изображения, ссылки, фокус, открытие Fancybox, переключение стрелкой и закрытие Escape/кнопкой. Результаты и скриншоты: `reference/montage-results.json`, `reference/montage-390.png`, `reference/montage-1440.png`.

В ограниченной Windows-песочнице сборке и Chrome может потребоваться разрешение на запуск процессов. Известные общепроектные предупреждения: Sass @import в Bootstrap и отсутствующая демонстрационная картинка ProductCard на главной. К ресурсам монтажа они не относятся.
