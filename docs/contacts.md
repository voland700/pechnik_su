# Контакты

Маршрут /about/contacts/ использует CatalogLayout без sidebar, общий Header/Footer и Breadcrumbs. Главная добавляется компонентом автоматически, промежуточная ссылка ведёт на /about/ (страница раздела не создаётся).

Данные двух магазинов находятся в src/data/stores.ts, контракт Store — src/types/store.ts. Полные адреса и отделы отличаются от сокращённых контактов шапки, её данные не изменены. StoreCard принимает store и необязательный eager. contacts допускает любое число телефонов, department необязателен. Изображения импортируются Astro с размерами, SVG — как локальные URL. Первая фотография eager, вторая lazy. Декоративные иконки исключены из озвучивания.

До 768 px карточки вертикальные, фотография занимает ширину. От 768 px фотография 224 px слева, контакты справа. Соотношение фото 3:2, object-fit: cover. Общие токены, focus-visible и shine, SCSS подключён через main.scss. Иерархия H1 → H2 Наши магазины → H3 магазинов.

Контейнер contacts-map__container имеет нейтральный фон, рамку и минимальную высоту 288 px на мобильных / 384 px от 768 px. Картографических API, iframe, имитации меток и нового JavaScript нет.

Для Битрикс заменить массив и URL данными CMS, сохранить классы и независимую разметку article. URL изображений можно передать через image.src/width/height. Содержимое contacts-map__container заменить компонентом карты.
